\# Good Morning React App



This is a simple frontend project created using ReactJS.



The webpage contains:

\- A Good Morning heading

\- Input fields for:

&#x20; - Name

&#x20; - Phone Number

&#x20; - Email Address

\- A Submit button



When the user clicks the submit button, a popup message is displayed.



\## Technologies Used

\- ReactJS

\- CSS



\## Purpose

This project was created as a frontend knowledge test task to demonstrate basic ReactJS concepts and simple user interface design.
